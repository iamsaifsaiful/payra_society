# পায়রা সমিতি অ্যাপ (Payra Society)

সদস্য ও অ্যাডমিনের Android অ্যাপ। WordPress প্লাগিন **Payra Enterprise Society Accounts v1.0.9.58+**-এর `payra/v1` API দিয়ে চলে — আলাদা সার্ভার লাগে না।

## এই ভার্সনে (ধাপ ১)
- প্রথমবার: সমিতির ওয়েবসাইটের ঠিকানা (APK বানানোর সময় দিলে আর জিজ্ঞেস করবে না)
- লগইন (সদস্য আইডি/মোবাইল/ইমেইল; অ্যাডমিন ইমেইল/ইউজারনেম), সেশন শেষ হলে নিজে লগইনে ফেরে
- সদস্য: হোম (মোট/বর্তমান ব্যালেন্স, উত্তোলনযোগ্য লাভ, বকেয়া সতর্কতা, প্রজেক্ট, সাম্প্রতিক লেনদেন) · সঞ্চয় · প্রজেক্ট · লেনদেন (ফিল্টার, সময়সীমা, চলতি ব্যালেন্স, রসিদ) · প্রোফাইল (তথ্য বদল, পাসওয়ার্ড, নোটিফিকেশন পছন্দ, বড় লেখা)
- নোটিফিকেশন, রসিদ (A4 পেজ — প্রিন্ট/PDF), সমিতির হিসাব
- অ্যাডমিন (ধাপ ২): ড্যাশবোর্ড · সদস্য (খোঁজা, হিসাব, লেনদেন, পাসওয়ার্ড রিসেট) · ➕ এন্ট্রি (সঞ্চয়, কিস্তি, পিনসহ উত্তোলন → রসিদ ও WhatsApp বোতাম) · আদায় (বকেয়া তালিকা, WhatsApp রিমাইন্ডার) · আরও (সব রসিদ, মাসিক সঞ্চয়/শেষ তারিখ/কোষাধ্যক্ষ/অ্যাপ আপডেটের সেটিং)
- ইন্টারনেট না থাকলে শেষবার আনা তথ্য দেখায়

## APK বানানো
GitHub Actions প্রতিটি push-এ analyze, test আর release APK বানায় (`payra-society-android` artifact)।
নির্দিষ্ট ওয়েবসাইট বসিয়ে বানাতে: Actions → Build app → Run workflow → `site`-এ ঠিকানা দিন।

লোকাল: `bash tool/setup_platforms.sh && flutter pub get && flutter run --dart-define=PAYRA_SITE=https://আপনার-সাইট`

ফন্ট: Noto Sans Bengali — স্পষ্ট বাংলা সংখ্যার জন্য (SIL OFL, `assets/fonts`-এ লাইসেন্স)।
